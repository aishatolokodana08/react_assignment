Title: Debugging a React Application Using React Developer Tools Introduction The purpose of this practical exercise was to understand how React Developer Tools can be used to inspect, debug, and fix problems in a React application. Procedure Created a sample React application using Vite. Installed React Developer Tools as a Chrome browser extension. Opened the application in the browser. Accessed the Components tab in the browser developer tools. Inspected the component tree to examine the application’s components, props, and state. Identified an incorrect initial state value in the Counter component. Corrected the state by using the initialCount prop. Tested the application to confirm that the counter and user profile worked correctly. Issues Identified and Solutions The Counter component initially displayed zero instead of the expected initial value of five. This happened because the state was initialized with zero rather than the initialCount prop. The issue was corrected by changing the initial state to use the initialCount prop. Results After debugging, the counter displayed the correct initial value and increased when the button was clicked. The UserProfile component also displayed the correct username. Conclusion This exercise demonstrated how React Developer Tools helps developers inspect component hierarchies, examine props and state, identify errors, and debug React applications. It makes the debugging process easier and helps developers understand how their components interact.
